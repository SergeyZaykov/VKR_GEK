## Порядок установки
1. Установить в браузере менеджер пользовательских скриптов, например, [Tampermonkey](https://www.tampermonkey.net/). Установка менеджера пользовательских скриптов производится как установка плагина к браузеру.
2. На странице этого проекта щелкните по файлу скрипта [For_all_students.user.js](For_all_students.user.js). В браузере откроется его текст.
3. Далее, нажимаете кнопку "Raw" (она вверху страницы). Файл скрипта  For_all_students.user.js сначала скачается, а потом откроется в менеджере пользовательских скриптов.
4. Менеджер пользовательских скриптов, скорее всего, попросит подтвердить установку скрипта For_all_students.user.js. В Tampermonkey для этого нажмите кнопку "Install".
5. Если скрипт For_all_students.user.js будет успешно установлен, окно менеджера пользовательских скриптов исчезнет.
6. На этом установка скрипта закончена. Можно начинать им пользоваться.
## Использование в Учебной нагрузке
1. Откройте [Учебную нагрузку](https://nagruzka.tsu.tula.ru:6443/nagruzka/) и слева в меню "Навигация" выберите кнопку "ИГА".
2. Далее, как обычно, выбираете кафедру и группу. Откроется список студентов группы и их тем.
3. Вверху страницы, в ряду кнопок, должна появиться кнопка "Комиссия всей группе", она будет самой правой. Если вы открыли Учебную нагрузку до установки скрипта, то обновите страницу.
4. Нажимаете на кнопку "Комиссия всей группе", выбираете нужную комиссию, затем нажимаете кнопку "Выбрать". Комиссия будет назначена всем студентам, **даже тем, кому уже была назначена другая комиссия ранее**.
5. Появится окно предупреждения, что скрипт не может показать назначенную комиссию. Поэтому откройте темы ВКР любой другой группы, а потом снова откройте темы ВКР группы, в которой назначали комиссию. Самая правая колонка "Комиссия" должна быть заполнена у всех студентов.
6. На этом всё! Если что-то не работает, вы знаете, как меня найти.
